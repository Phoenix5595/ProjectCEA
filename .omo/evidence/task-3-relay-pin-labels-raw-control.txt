Changes made:

3. Added call in run_control_loop (after _expire_manual_overrides):
   try:
       await self._expire_raw_channel_overrides()
   except Exception as e:
       logger.error(f"Failed to expire raw channel overrides: {e}")
4. Added method _expire_raw_channel_overrides:
   - Checks automation_redis and redis_client are not None, returns early if so
   - Loops channel 0-15
   - Builds key via relay_raw_override_key(channel)
   - Reads raw value via asyncio.to_thread(redis_client.get, key)
   - Parses JSON payload, extracts expires_at
   - If expired (expires_at <= datetime.now(UTC)):
     * await self.relay_manager.set_channel_state(channel, 0)
     * await asyncio.to_thread(redis_client.delete, key)
     * logger.info(f"Raw channel {channel} manual override expired, turned OFF")
   - Skips future expires_at and missing keys
