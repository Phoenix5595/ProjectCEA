Task 5: Configure Nextcloud settings via occ command
=====================================================

Date: 2026-06-22
Host: iskradocker (100.123.38.1)
Nextcloud Version: 32.0.11.1

---

1. SET default_phone_region TO 'CA'
   Command: docker exec --user www-data nextcloud-app php occ config:system:set default_phone_region --value="CA"
   Result: System config value default_phone_region set to string CA
   Status: SUCCESS

2. SET maintenance_window_start TO 2 (integer)
   Command: docker exec --user www-data nextcloud-app php occ config:system:set maintenance_window_start --type=integer --value=2
   Result: System config value maintenance_window_start set to integer 2
   Status: SUCCESS

3. VERIFY trusted_domains
   Command: docker exec --user www-data nextcloud-app php occ config:system:get trusted_domains
