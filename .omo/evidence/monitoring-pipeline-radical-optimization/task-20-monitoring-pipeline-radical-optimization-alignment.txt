# T20 — Static panel alignment and live-tail updates

## Delivered

- Split historical alignment into `alignSeriesBase()` and `applyLiveTail()`.
  The base builds the sorted grid only from historical inputs; the tail updates
  the current live sensor slot without re-sorting or re-gridding history.
- Added a per-panel `createPanelAlignment()` cache. Its base key is the
  historical sensor series, control history, projection history, photoperiod,
  range, point budget, and panel. Its tail key is the live-values reference and
  UTC second.
- Chart groups now hold separate persistent climate/device panel caches, so the
  Flower and Veg pages filter panel inputs before their respective alignments.
- `AlignInput.maxPoints` is clamped to the T19 `MAX_BUDGET` ceiling of 20,000,
  preventing oversized legacy no-budget payloads from growing chart buffers.

## Acceptance coverage

- Legacy parity: split output equals legacy output, including series, bands,
  provenance, and explicit null gaps.
- 120 static-history live ticks: exactly one base alignment and 120 bounded
  tail updates; the final live mean is present at the tail index.
- A changed control-history object invalidates the panel base exactly once.
- Unrelated pressure input is absent from the temperature panel grid and bands.
- A 20,100-point legacy input constrained with `maxPoints: 100000` produces at
  most 20,000 chart points.
