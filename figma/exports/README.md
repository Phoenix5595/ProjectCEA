# Exports (from Figma → app)

Put any assets you export from Figma here so the repo keeps a single, predictable source.

## Suggested structure

- `exports/icons/` (SVG preferred)
- `exports/images/` (PNG/WebP as needed)

## Naming conventions

- Prefer kebab-case: `relay-channel-on.svg`, `zone-card-bg.png`
- Keep exports deterministic (same filename for same semantic asset)
